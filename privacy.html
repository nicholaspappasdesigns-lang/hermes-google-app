Privacy Policy

Hermes Google App. Last updated October 20, 2026.

This application is a personal-use tool operated by a single individual, the Google account owner. It accesses only that person's own Google data (Drive, Calendar, Docs, Sheets, Contacts, and Gmail) in order to carry out tasks the owner explicitly requests.

What is collected

No data is collected beyond what the owner's own Google account already contains. There is no analytics, no tracking, no advertising, and no profiling.

Where data is stored

Data stays on the owner's own machine and within the owner's own Google account. Nothing is transmitted to the developer or to any third party.

Sharing

No data is sold, shared, or disclosed to anyone. Google API data is not used to train or improve any machine-learning model.

Limited use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
