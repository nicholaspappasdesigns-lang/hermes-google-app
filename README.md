# Hermes Google App

Personal-use OAuth application that connects a self-hosted Hermes agent
(Nous Research) to Google Drive, Calendar, Docs, Sheets, Contacts, and Gmail
for a single user: the account owner.

## What it does

The application lets its owner ask an AI assistant to read and write files in
their own Google Drive, create and edit Docs and Sheets, view and create
Calendar events, and read or send Gmail — all on their own account.

## Who uses it

One person. It is not distributed, published, or offered as a service, and it
has no users other than the account owner.

## Data handling

Data is read only from the owner's own Google account, on the owner's own
machine, at the owner's request. Nothing is shared with third parties, and no
analytics or tracking is performed.
